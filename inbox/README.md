# Inbox

[Home](../README.md) · [Topics](../docs/topics.md) · [Reading queue](../LATEST.md)

Capture questions, sources, and unfinished notes here. Use a dated filename such as `YYYY-MM-DD-topic.md`, or run `python3 scripts/new_note.py inbox "Your idea"` from the repository root.

When an idea is ready, move it to the closest topic folder and update its existing link in the reading queue. Link it from the topic index.
