# Repository instructions

- When adding content to this repository, commit the changes and push them to `main`.
- Add a dated, unchecked entry to [Latest learning](docs/LATEST.md) for each new note or substantial revision. Preserve existing review checkboxes and follow the [note maintenance guide](docs/CONTRIBUTING.md).
- Present notes through realistic events or incidents when appropriate, without labeling scenarios as fictional. Do not present invented events as verified history.
- Use tables where they make notes easier to read, such as for interpreting command output or comparing options.
